## 🚀 اجرای سریع

۱. فایل‌ها را در یک پوشه بریزید  
۲. فایل `index.html` را با مرورگر باز کنید  
۳. تمام! فروشگاه آماده است.

---

## 🔐 ورود به پنل مدیریت

- از فوتر → «پنل مدیریت»
- رمز پیش‌فرض: `mehrshop123`
- بعد از ورود، رمز را از پنل تغییر دهید.

---

## 🌐 انتشار روی اینترنت

### روش ۱ — GitHub Pages
1. فایل‌ها را در یک ریپازیتوری GitHub آپلود کنید
2. Settings → Pages
3. Branch: main → Save
4. سایت روی `username.github.io/repo-name` منتشر می‌شود

### روش ۲ — Vercel
1. به [vercel.com](https://vercel.com) بروید
2. با GitHub وارد شوید
3. ریپازیتوری را انتخاب کنید
4. Deploy

---

## 🗄️ اتصال به دیتابیس واقعی

برای اینکه اطلاعات روی سرور ذخیره شوند:

1. یک پروژه در [supabase.com](https://supabase.com) بسازید
2. فایل `supabase.sql` را در SQL Editor اجرا کنید
3. URL و Anon Key را در پنل ادمین وارد کنید
